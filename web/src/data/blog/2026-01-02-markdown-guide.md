这是第二篇示例文章，用来演示 Markdown 的常用写法。

## 标题分级

`#` 到 `######` 对应六级标题，文章内一般从 `##` 开始用。

## 文字样式

**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

- 无序列表用 `-`
- 第二项
  - 嵌套缩进两个空格

1. 有序列表用数字
2. 第二项

## 代码块

```js
// 写文章的 frontmatter 示例
const post = {
  title: "Hello World",
  pubDatetime: "2026-01-01T09:00:00+08:00",
  tags: ["示例"],
};
```

## 引用和分割线

> 引用块适合放一句话摘要或者转载声明。
